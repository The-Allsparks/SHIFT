# SHIFT examples

| File | Purpose |
| ---- | ------- |
| [profiles/competition-example.json](profiles/competition-example.json) | AllSparks-style demonstration: driver sticks/helm, co-driver layers, chords, analog predicate, feedback |

Java illustration: `shift-examples` module, `ShiftExampleOpMode` (`@Disabled`).

These profiles contain **semantic intents only**. They do not include motor powers, servo positions, or encoder counts.
