# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Do **not** open a public issue for problems that could put robots or students at risk.

Preferred: [GitHub Private Vulnerability Reporting](https://github.com/The-Allsparks/SHIFT/security/advisories/new).

SHIFT does not command motors. Still treat unexpected intent emission, disabled fallback, or profile validation bypass as defects.

Never store passwords, Wi-Fi credentials, API keys, or tokens in the repository.
